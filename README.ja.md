# 🛡️ MyPass (パスワードマネージャー)

安全で直感的なローカルベースのパスワード管理プログラムです。

## 📌 主な機能
* **安全なローカル暗号化保存:** 外部サーバーに依存せず、重要なアカウント情報とパスワードをローカル環境に安全に暗号化して保管します。
* **直感的なユーザーインターフェース:** 複雑な設定なしで、誰でも簡単かつ迅速にアカウント情報の追加、編集、照会が行えます。
* **多言語対応:** 韓国語を基本として、様々な言語環境を考慮して設計されています。
