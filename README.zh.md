# 🛡️ MyPass (密码管理器)

一个安全且直观的本地密码管理应用程序。

## 📌 主要功能
* **安全的本地加密存储：** 无需依赖外部服务器，在本地环境中安全加密并妥善保管您的敏感账户信息和密码。
* **直观的用户界面：** 无需复杂的配置，任何人都可以轻松快速地添加、修改和查询账户信息。
* **多语言支持：** 考虑到了各种语言环境，提供韩语、英语、日语、中文等多语言支持。
