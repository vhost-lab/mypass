# MyPass 安装·使用指南

[설치가이드.md](../ko/설치가이드.md) · [install-guide.md](../en/install-guide.md) · [install-guide.md](../ja/install-guide.md) · [install-guide.md](install-guide.md)

## 0. 请先了解

- **使用者**：只需要 `MyPass.exe` 一个文件即可。不需要 Python，也不需要安装程序。
- **制作 exe 的人**（每台电脑只需做一次）：需要 Python。→ 请参考第 4 项
- **如果忘记主密码，将无法恢复。** 请务必牢记。

## 1. 安装（已拿到 exe 的情况）

1. 将 `MyPass.exe` 放到任意文件夹中。例如：`D:\MyPass\`
   - 请避免放在像 `C:\Program Files` 这样没有写入权限的位置。（如果无法写入，信息会保存到 `%APPDATA%\마이패스\data` 中）
2. 双击运行。运行后会在 exe 旁边生成 `data` 文件夹。**所有信息只会保存在这个文件夹中。**
3. 首次运行时可能会弹出蓝色的"Windows 已保护你的电脑"窗口。（因为是未签名的个人程序而出现的警告）
   → 点击 `更多信息` → `仍要运行`。如果杀毒软件产生怀疑，请将该 exe 添加为例外。

## 2. 首次使用

1. 在登录窗口中点击 `新用户(N)` → 设置账号和**主密码**
2. `管理(T) → 添加网站` (Ctrl+N)：输入网站说明、地址、账号、密码
   - 可以创建分组进行归类，也可以在列表中拖放移动。
3. 在浏览器中打开对应网站时，地址会自动关联，并显示匹配的信息。（`自动关联浏览器地址`，按 F5 可手动获取）
4. `填充` 按钮：会在登录窗口中自动输入账号/密码。（勾选 `填充后按 Enter 键(自动登录)` 选项可自动登录）
   - 浏览器关联和填充功能使用的是 Windows 的辅助功能（UI Automation），因此根据网站和浏览器的不同，动作可能会有差异。如果无法使用，请使用账号/密码的复制按钮。
5. 10 分钟内无操作将自动锁定。
6. `Ctrl+F`（或放大镜按钮）：打开搜索框，可按说明、地址、关键词、账号一次性查找网站。

## 3. 备份（请务必设置）

- **自动备份**：每次登录时，都会在 `data\backup` 中累积加密备份。（保留最近 10 个）
- **备份位置**：在 `文件(F) → 设置备份位置...` 中指定文件夹后，加密备份会自动保存到该文件夹（`MyPass_backup`）中。
  - 其他驱动器、外置硬盘、NAS、OneDrive·谷歌云端硬盘·Dropbox 等云同步文件夹均可使用
  - 建议使用与程序所在文件夹（USB）**不同的设备**。如果该设备发生故障，原始数据和备份会同时丢失。
  - CSV 格式不会被加密，请尽量避免使用。
- **恢复**：在登录窗口或 `文件(F) → 从备份恢复...` 中进行。

## 4. 制作 exe（仅限制作者，首次进行一次即可）

**请打开 `빌드가이드.zh.md`，从第 1 步开始依次操作。**（从安装 Python → 准备文件夹 → 制作 → 确认运行，全部都有详细说明）
- 概要：安装 Python → 将 `mypass_package.zip` 中的文件（`mypass.py`、`mypass_i18n.py`、`build.bat`、`requirements.txt`、`fonts` 文件夹、`icon.ico` 等）放入同一文件夹 → 双击 `build.bat` → 生成 `dist\MyPass.exe`

## 5. 放入 U 盘随身携带

- 将 `MyPass.exe` 和 `data` 文件夹一起放入 U 盘的某个文件夹中，直接在 U 盘上运行即可。
- 即使在多台电脑上使用，信息也只存在于 U 盘的 `data` 中。
- 如果 U 盘为写保护（只读）状态，信息会单独保存到该电脑的 `%APPDATA%` 中。请注意这一点。
- 为防止丢失，请将主密码设置得足够长，并单独指定备份位置。

## 6. 更新

- 仓库地址已预先填写在 `mypass.py` 开头的 `UPDATE_REPO = "vhost-lab/mypass"` 中。如果仓库名称不同，只需修改这一行后重新构建即可。
- 通过 `更新(U) → 检查更新` 可以立即检查，登录时也会每天自动检查一次并通知。
- 如果有新版本，窗口中会出现 **[立即更新]** 按钮。点击后会下载新 exe 并自动替换，然后重新启动程序。（仅在以 exe 方式运行时可用。以 `python mypass.py` 方式直接运行时，只会打开下载页面）
- 在 `更新(U) → 更新设置...` 中可以开启/关闭自动检查，并输入私有仓库所需的只读令牌。
- 要发布新版本，请在 GitHub 仓库的 Releases 中添加如 `v2.0` 这样的标签来创建新版本，**并务必将 exe 文件作为该 Release 的附件（Assets）一并上传。**（只有上传了 exe 附件，[立即更新] 才会出现）
- Windows 杀毒软件可能会以"下载并运行未签名的 exe"为由阻止自动更新或发出警告。如果想扩大分发范围，建议获取代码签名证书。

## 版权标识

在 `mypass.py` 开头的 `COPYRIGHT_HOLDER` 中填写的名称，会以 `ⓒ 年份 名称` 的格式显示在关于（About）窗口中。如需更改，只需修改这一行即可。

## 语言

- 首次运行时会弹出语言（한국어/English/日本語/简体中文）选择窗口，之后也可以在 `设置(S) → 语言 (Language)` 中直接切换。
- 如需添加更多语言，请按照 `mypass_i18n.py` 中的说明，在 `LANGS`、`TR`、`CSV_HEAD` 中添加即可。
- 在通知中点击 `打开下载页面` → 下载新的 `MyPass.exe`，**只替换原有的 exe 文件**。`data` 文件夹请保持不动。
- 替换前先执行一次 `文件(F) → 创建备份...` 会更安全。
- 私有（private）仓库需要只读令牌。（请参考设置窗口中的说明）

## 7. 问题解决

| 症状 | 解决方法 |
|---|---|
| 无法运行 / 刚打开就消失 | 将其加入杀毒软件例外，在其他文件夹（例如非桌面的 D:\）中运行 |
| 信息似乎消失了 | 如果之前在其他文件夹运行过，请检查该文件夹的 `data` 或 `%APPDATA%\마이패스\data`（`帮助(H) → 关于 → 打开数据文件夹`） |
| 浏览器地址无法读取 | 按 `F5`，点击一下浏览器后重试。如果仍不行，请直接手动输入地址 |
| 检查更新失败 | 请确认网络连接、仓库名称，以及（如为私有仓库时）令牌是否正确 |
| 密码丢失 | 无法恢复。如果有记得密码的备份，可通过 `从备份恢复` |

## 8. 须知事项

- 本程序不会将信息发送到互联网。互联网仅用于检查更新（查询最新版本号）。
- 加密方式：AES-256-GCM，密钥生成：scrypt
- 请勿将包含个人信息的 `data` 文件夹、`.mpbak`、`.csv` 文件上传到 GitHub 等平台。（随附提供的 `.gitignore` 会自动阻止这一点）
