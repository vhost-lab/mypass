# MyPass（我的密码）

[한국어](../ko/README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [简体中文](README.md)

一款面向 Windows 的账号密码加密管理程序。信息不会通过互联网发送，只会加密保存在程序旁边（或 U 盘上）的 `data` 文件夹中。

## 主要功能

- **加密方式**：AES-256-GCM + scrypt。没有主密码无法打开。
- **多用户**：同一台电脑上，多个人（或不同用途）可以各自使用完全独立的密码库。
- **分组管理**：将网站归入分组（文件夹），可拖拽移动。
- **搜索**：按 `Ctrl+F` 即可按说明、地址、关键词、账号一次性查找网站。
- **浏览器地址联动与自动填充**：自动读取 Chrome、Edge、Whale 等浏览器的地址栏，并可自动填入账号和密码。（仅限 Windows，基于 UI Automation）
- **备份**：每次登录自动备份；也可设置自动/手动备份到任意位置（U 盘、云同步文件夹等）。默认使用加密备份，如需要也可导出未加密的 CSV（会有提示警告）。
- **U 盘便携使用**：`data` 文件夹就在 exe 旁边，可整体放入 U 盘，在其他电脑上直接使用。
- **更新提醒与一键更新**：检测到新版本会提醒，若以 exe 方式运行，点击【立即更新】即可自动下载、替换并重启。联网仅用于检查版本，不会发送已保存的信息。
- **多语言**：한국어 · English · 日本語 · 简体中文。首次启动时选择，或随时在"环境设置 → 语言"中切换。

## 下载使用

从本仓库的 **Releases** 中获取最新的 `MyPass.exe` 并运行即可，无需安装 Python。exe 旁边会自动生成 `data` 文件夹，所有信息都会加密保存在其中。（可将 exe 和 `data` 文件夹一起放入 U 盘携带）

## 从源码自行构建

从源码构建的详细步骤见 [install-guide.md](install-guide.md) 和 [build-guide.md](build-guide.md)。如需进一步加固保护后再构建，请参考 [protection-guide.md](protection-guide.md)。

## 发布新版本（维护者用）

在 GitHub 的 Releases 中创建高于当前版本号的标签（例如 `v2.1`），**并务必将 exe 作为附件（Assets）一并上传。** 程序会检查 `mypass.py` 中 `UPDATE_REPO`（默认 `vhost-lab/mypass`）预设仓库的最新 Release，提醒用户有新版本；若附带了 exe，用户点击【立即更新】即可自动替换并重启。（菜单：更新）

## 安全性

- 所有信息均使用 AES-256-GCM 加密，仅保存在本机，不会通过互联网传输。
- 互联网仅用于检查更新（以及应用更新时下载新的 exe），已保存的信息不会被发送。
