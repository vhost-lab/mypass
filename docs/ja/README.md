# MyPass（マイパス）

[한국어](../ko/README.md) · [English](../en/README.md) · [日本語](README.md) · [简体中文](../zh-CN/README.md)

Windows向けの、ID・パスワード・サイト情報を暗号化して保管する個人用パスワード管理プログラムです。情報はインターネットに送信されず、このパソコン（またはUSB）の `data` フォルダの中にのみ暗号化して保存されます。

## 主な機能

- **暗号化**: AES-256-GCM + scrypt。マスターパスワードなしでは開けません。
- **複数ユーザー**: 1台のパソコンで複数の人（または用途別）がそれぞれ独立した保管庫を使えます。
- **グループ（フォルダ）管理**: サイトをグループにまとめ、ドラッグ＆ドロップで移動できます。
- **検索**: `Ctrl+F` でサイトの説明・アドレス・キーワード・IDを一度に検索できます。
- **ブラウザアドレス連携・自動入力**: Chrome・Edge・Whale などのアドレスバーを自動で読み取り、IDとパスワードを自動入力します。（Windows専用、UI Automation使用）
- **バックアップ**: ログインのたびに自動バックアップ。好きな場所（USB・クラウド同期フォルダなど）への自動/手動バックアップにも対応。既定は暗号化バックアップで、必要なら暗号化されていないCSVでも書き出せます（警告表示あり）。
- **USBで持ち運び**: exeの隣に `data` フォルダを置く構成なので、USBにまるごと入れて別のパソコンでもすぐ使えます。
- **アップデート通知・自動適用**: 新しいバージョンが出ると知らせ、exeとして実行中であれば［今すぐアップデート］を押すだけで新バージョンを取得・入れ替え・再起動まで行います。通信するのはバージョン確認のみで、保存した情報は送信されません。
- **多言語対応**: 한국어・English・日本語・简体中文。初回起動時に選択するか、「環境設定 → 言語」からいつでも変更できます。

## ダウンロードして使う

このリポジトリの **Releases** から最新の `MyPass.exe` を取得して実行するだけです。Pythonのインストールは不要です。exeの隣に `data` フォルダが自動的に作られ、すべての情報はその中に暗号化されて保存されます。（exeと `data` フォルダを一緒にUSBへ入れて持ち運べます）

## ソースからビルドする

ビルド手順は [install-guide.md](install-guide.md) と [build-guide.md](build-guide.md) に、最初から最後まで順番にまとまっています。コードをさらに保護してビルドしたい場合は [protection-guide.md](protection-guide.md) を参照してください。

## 新バージョンの公開（管理者向け）

GitHub の Releases で現在のバージョンより大きいタグ（例: `v2.2`）を作成し、**必ずexeをアセット（Assets）として添付してください。** `mypass.py` 内の `UPDATE_REPO`（既定値 `vhost-lab/mypass`）にあらかじめ指定されたリポジトリの最新リリースを確認して利用者に新バージョンを知らせ、exeが添付されていれば［今すぐアップデート］で自動的に入れ替え・再起動まで行います。（メニュー: アップデート）

## 安全性

- すべての情報はAES-256-GCMで暗号化され、このパソコンにのみ保存されます。インターネットには送信されません。
- インターネットはアップデート確認（および適用時の新しいexeのダウンロード）にのみ使用され、保存された情報が送信されることはありません。
