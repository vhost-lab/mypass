# MyPass インストール・使用ガイド

[설치가이드.md](../ko/설치가이드.md) · [install-guide.md](../en/install-guide.md) · [install-guide.md](install-guide.md) · [install-guide.md](../zh-CN/install-guide.md)

## 0. まず知っておくこと
- **使う人**: `MyPass.exe` が1つあれば大丈夫です。Python・インストールプログラムは不要です。
- **exeを作る人**(1台のPCで1回だけ): Pythonが必要です。 → 4番を参照
- **マスターパスワードを忘れると復旧する方法がありません。** 必ず覚えておいてください。

## 1. インストール (exeを受け取った場合)
1. `MyPass.exe` を好きなフォルダーに置きます。例: `D:\MyPass\`
   - `C:\Program Files` のような書き込み権限のない場所は避けてください。(書き込みできない場合、情報は `%APPDATA%\マイパス\data` に保存されます)
2. ダブルクリックで実行します。実行するとexeの横に `data` フォルダーが作られます。**すべての情報はこのフォルダーにのみ保存されます。**
3. 初回実行時に「Windows によって PC が保護されました」という青い画面が表示されることがあります。(署名のない個人プログラムのため表示される警告です)
   → `詳細情報` → `実行` を押してください。ウイルス対策ソフトが疑わしいと判断した場合は、該当のexeを例外として登録してください。

## 2. 初めて使う
1. ログイン画面で `新規ユーザー(N)` → IDと**マスターパスワード**を設定
2. `管理(T) → サイトを追加` (Ctrl+N): サイトの説明、アドレス、ID、パスワードを入力
   - グループを作ってまとめることができ、一覧からドラッグ&ドロップで移動できます。
3. ブラウザーで該当サイトを開くと、アドレスが自動で連携され、該当する情報が表示されます。(`ブラウザーのアドレス自動連携`、F5で手動取得)
4. `入力` ボタン: ログイン画面にID/パスワードを入力してくれます。(`入力後にEnterキーを押す(自動ログイン)` オプションで自動ログイン)
   - ブラウザー連携・入力はWindowsのアクセシビリティ機能(UI Automation)を使用するため、サイトやブラウザーによって動作が異なる場合があります。うまく動作しない場合はID/パスワードのコピーボタンをお使いください。
5. 10分間操作がないと自動的にロックされます。
6. `Ctrl+F`（または虫眼鏡ボタン）: サイトの説明・アドレス・キーワード・IDを一度に検索できる検索ボックスが開きます。

## 3. バックアップ (必ず設定してください)
- **自動バックアップ**: ログインするたびに `data\backup` に暗号化バックアップが蓄積されます。(最新10個を保管)
- **バックアップ先**: `ファイル(F) → バックアップ先の設定...` でフォルダーを指定すると、そのフォルダー(`MyPass_backup`)に暗号化バックアップが自動保存されます。
  - 他のドライブ、外付けハードディスク、NAS、OneDrive・Googleドライブ・Dropboxのようなクラウド同期フォルダー、いずれも使用可能です
  - プログラムフォルダー(USB)とは**別の装置**を推奨します。その装置が故障すると、元データとバックアップが一緒に消えてしまいます。
  - CSV形式は暗号化されないため、なるべく使用しないでください。
- **復元**: ログイン画面、または `ファイル(F) → バックアップから復元...`

## 4. exeを作る (作る人のみ、最初の1回)
**`빌드가이드.ja.md` を開いて1段階から順番に進めてください。**(Pythonのインストール → フォルダー準備 → 作成 → 実行確認まですべて書かれています)
- 要約: Pythonのインストール → `mypass_package.zip` 内のファイル（`mypass.py`、`mypass_i18n.py`、`build.bat`、`requirements.txt`、`fonts` フォルダー、`icon.ico` など）を1つのフォルダーに → `build.bat` をダブルクリック → `dist\MyPass.exe`

## 5. USBに入れて持ち歩く
- `MyPass.exe` と `data` フォルダーをUSBの1つのフォルダーに一緒に置き、USBから直接実行すればよいです。
- 複数のPCで使っても、情報はUSBの `data` にのみ存在します。
- USBが書き込み禁止(読み取り専用)の場合、情報はそのPCの `%APPDATA%` に別途保存されます。ご注意ください。
- 紛失に備えてマスターパスワードを十分に長くし、バックアップ先を別途指定してください。

## 6. アップデート
- リポジトリのアドレスは `mypass.py` の先頭にある `UPDATE_REPO = "vhost-lab/mypass"` にあらかじめ入っています。リポジトリ名が異なる場合は、この行だけを修正してから再ビルドしてください。
- `アップデート(U) → アップデートを確認` ですぐに確認でき、ログイン時に1日1回自動で確認してお知らせします。
- 新しいバージョンがあると、画面に**【今すぐアップデート】**ボタンが表示されます。押すと新しいexeをダウンロードして自動で入れ替え、プログラムを再起動します。(exeで実行中の場合のみ可能です。`python mypass.py` で直接実行している場合はダウンロードページが開くだけです)
- `アップデート(U) → アップデート設定...` では自動確認のオン/オフと、非公開リポジトリ用の読み取り専用トークンを入力します。
- 新しいバージョンを配布するには、GitHubリポジトリのReleasesで `v2.2` のようにタグを付けて新しいリリースを作成し、**exeファイルをReleaseの添付ファイル(Assets)として必ず一緒にアップロードしてください。**(添付されたexeがないと【今すぐアップデート】が表示されません)
- Windowsのウイルス対策ソフトが「署名されていないexeをダウンロードして実行する」という理由で自動アップデートを妨げたり警告したりすることがあります。配布を広げたい場合はコード署名証明書を取得することをお勧めします。

## 著作権表示
`mypass.py` の先頭にある `COPYRIGHT_HOLDER` に入れた名前が、バージョン情報(About)画面に `ⓒ 今年の年 名前` の形式で表示されます。変更するにはその1行だけを修正してください。

## 言語
- 初回実行時に言語(한국어/English/日本語/简体中文)選択画面が表示され、その後は `環境設定(S) → 言語` でいつでも変更できます。
- 言語を追加したい場合は `mypass_i18n.py` 内の説明の通りに `LANGS` と `TR`、`CSV_HEAD` に追加してください。
- 通知から `ダウンロードページを開く` → 新しい `MyPass.exe` を受け取り、**既存のexeファイルのみ置き換えます。**`data` フォルダーはそのままにしておいてください。
- 置き換える前に `ファイル(F) → バックアップを作成...` を一度行っておくと安全です。
- 非公開(private)リポジトリの場合は読み取り専用トークンが必要です。(設定画面の案内を参照)

## 共用アカウント（複数人で同じ一覧を一緒に使う）
- `環境設定 → 共用アカウント設定...` でIDを1つとフォルダ（会社の共有ドライブなど）を指定すると、そのIDでログインするときだけこのパソコンではなくそのフォルダの保管庫を読み書きします。
- 一緒に使うすべてのPCに**同じID・同じフォルダパス**を同様に設定して初めて、全員が同じ一覧を見られます。
- それ以外のID（個人用）は今まで通り各自のパソコンにのみ保存され、互いに影響しません。
- 共有フォルダに接続できない場合（ネットワーク切断など）、そのIDではログインが拒否され案内メッセージだけが表示されます — 代わりにローカルファイルが作られることはありません。
- そのアカウントの自動バックアップも、ローカルではなくその共有フォルダ内の `backup` にたまります。
- **同時保存の衝突防止**: 他のPCが先に保存した後に保存しようとすると、「他のPCが先に保存しました」と再確認されます。そのまま上書きするか、保存を取り消してそのPCの最新内容を読み込むかを選べるため、変更内容が静かに消えることはありません。
- **変更履歴の表示**: `管理 → 変更履歴を見る` で、いつ・どのPC名で保存があったかを最新順に確認できます。（誰が何を変えたかではなく、保存時刻とPCのみ記録されます）
- **接続状態のリアルタイム監視**: ログイン後も定期的に共有フォルダの接続を再確認し、ネットワークが切れると画面下部のステータスバーにすぐ警告が表示されます。
- **変更の即時反映通知**: 他のPCが新しく保存した内容があると、画面下部のステータスバーに「他のPCで変更された内容があります」という通知が表示され、クリックすると再ログインせずに最新内容へ更新されます。

## 7. トラブルシューティング
| 症状 | 対処法 |
|---|---|
| 実行できない / すぐに消える | ウイルス対策ソフトの例外登録、別のフォルダー(例: デスクトップではなくD:\)で実行 |
| 情報が消えたように見える | 以前に別のフォルダーで実行していた場合は、そのフォルダーの `data` または `%APPDATA%\マイパス\data` を確認(`ヘルプ(H) → バージョン情報 → データフォルダーを開く`) |
| ブラウザーのアドレスが読み取れない | `F5`、ブラウザーを一度クリックしてから再試行。それでもだめな場合はアドレスを直接入力 |
| アップデートの確認に失敗する | インターネット接続、リポジトリ名、(非公開の場合は)トークンを確認 |
| パスワードを紛失した | 復旧不可。パスワードを覚えているバックアップがあれば `バックアップから復元` |

## 8. 知っておくべきこと
- プログラムはインターネットに情報を送信しません。インターネットはアップデート確認(最新バージョン番号の照会)にのみ使用されます。
- 暗号化: AES-256-GCM、鍵生成: scrypt
- 個人情報が含まれる `data` フォルダー、`.mpbak`、`.csv` ファイルはGitHubなどにアップロードしないでください。(同梱の `.gitignore` が防いでくれます)
