# exe 만들기 가이드 (처음부터 끝까지 순서대로)

> 이 가이드는 **MyPass.exe 를 만드는 사람**용입니다. (한 PC에서 한 번만 하면 됩니다)
> 만들어진 exe 를 쓰는 사람은 파이썬이 필요 없습니다. → `설치가이드.md` 참고
> 아래 순서를 **위에서부터 그대로** 따라 하세요. `이런 모양의 글자`는 그대로 입력하는 명령입니다.

소요 시간: 처음 약 10~15분 (대부분 설치와 내려받기 시간)
필요한 것: Windows 10/11 PC, 인터넷 연결

---

## 1단계. 파이썬 설치하기

1. 인터넷 브라우저에서 **https://www.python.org/downloads/** 를 엽니다.
2. 노란 버튼 **`Download Python 3.x.x`** 를 눌러 설치 파일을 받습니다. (3.10 이상이면 어느 버전이든 됩니다)
3. 받은 파일(`python-3.x.x-amd64.exe`)을 더블클릭해서 실행합니다.
4. 첫 화면 **맨 아래**에 있는 **`Add python.exe to PATH`** 칸을 **반드시 체크**합니다. ← 가장 중요
5. **`Install Now`** 를 누릅니다. (권한 확인 창이 뜨면 `예`)
6. `Setup was successful` 이 나오면 **`Close`** 를 누릅니다.

### 설치 확인
1. 키보드에서 **`Windows 키 + R`** 을 누르고, 입력칸에 `cmd` 를 쓰고 Enter → 검은 창(명령 프롬프트)이 열립니다.
2. 아래를 입력하고 Enter:

   `python --version`

3. `Python 3.12.x` 처럼 버전이 나오면 성공입니다. 검은 창은 닫아도 됩니다. (`exit` 입력 후 Enter)

> 만약 `Python was not found` 라고 나오거나 Microsoft Store 가 열리면 → 맨 아래 **[문제 해결 1번]** 을 보세요.

---

## 2단계. 작업 폴더 만들고 파일 넣기

1. 탐색기에서 **C 드라이브**에 `mypass_build` 폴더를 새로 만듭니다. → `C:\mypass_build`
   (한글·공백이 없는 짧은 경로를 쓰면 오류가 적습니다. **다른 폴더에 풀어도 되며**, 그 경우 아래의 `C:\mypass_build` 는 "내가 파일을 넣은 폴더"로 바꿔 읽으세요. 결과물은 그 폴더 안의 `dist\MyPass.exe` 입니다.)
2. 받은 `mypass_package.zip` 의 압축을 풉니다. (zip 우클릭 → `압축 풀기` 또는 `모두 압축 풀기`)
3. 압축을 풀면 `mypass` 폴더가 나옵니다. 그 **안의 파일들**을 `C:\mypass_build` 안으로 옮깁니다.
4. `C:\mypass_build` 를 열었을 때 **아래 항목들이 바로 보여야** 합니다. (폴더 안의 폴더가 아니라, 바로 이 폴더 안에)

   - `mypass.py`
   - `build.bat`
   - `requirements.txt` (설치할 패키지 목록 — build.bat 가 자동으로 읽어서 한 번에 설치함)
   - `fonts` 폴더 (프로그램에서 쓰는 글꼴 — exe 를 만들 때 자동으로 결과물 옆에 복사됨)
   - `icon.ico`

## 3단계. exe 만들기

### 방법 A. 가장 쉬운 방법 (권장)

1. `C:\mypass_build` 폴더에서 **`build.bat` 를 더블클릭**합니다.
2. 검은 창이 열리고 글자가 쭉 올라갑니다. **닫지 말고 기다립니다.** (처음엔 3~10분, 인터넷 속도에 따라 다름)
   - `[0/4]` 파이썬 확인 → `[1/4]` 가상환경 → `[2/4]` 패키지 설치 → `[3/4]` exe 만드는 중 → `[4/4] 완료`
   - 중간에 `WARNING` 이 나와도 정상입니다. `ERROR` 로 멈추면 **[문제 해결]** 을 보세요.
3. 마지막에 `결과물: ...\dist\MyPass.exe` 와 `계속하려면 아무 키나 누르십시오` 가 나오면 성공입니다. 아무 키나 눌러 창을 닫습니다.
4. `C:\mypass_build\dist\MyPass.exe` 가 만들어졌는지 확인합니다. → **5단계**로 가세요.

> Windows 가 "PC를 보호했습니다" 창을 띄우면 `추가 정보` → `실행` 을 누르세요.

### 방법 B. 직접 입력하는 방법 (방법 A 가 안 될 때)

**B-1. 명령 프롬프트를 작업 폴더에서 열기**
1. 탐색기로 `C:\mypass_build` 폴더를 엽니다.
2. 창 위쪽 **주소 표시줄**(`C:\mypass_build` 라고 적힌 곳)을 한 번 클릭합니다.
3. 적힌 글자를 지우고 `cmd` 라고 입력한 뒤 Enter. → 검은 창이 열리고 맨 앞에 `C:\mypass_build>` 가 보여야 합니다.

**어떤 검은 창을 쓰든 (cmd / PowerShell / Git Bash)** — 아래 명령 맨 앞의 `.venv\Scripts\python.exe` 부분만 창 종류에 맞게 바꿔 입력하세요. (나머지는 동일)

| 창 종류 | 맨 앞 부분을 이렇게 |
|---|---|
| 명령 프롬프트(cmd) | `.venv\Scripts\python.exe` (아래 적힌 그대로) |
| PowerShell | `.\.venv\Scripts\python.exe` (맨 앞에 `.\` 를 붙임) |
| Git Bash (bash) | `./.venv/Scripts/python.exe` (슬래시 `/` 사용) |

처음 `python -m venv .venv` 는 세 창 모두 똑같이 입력합니다.
(어느 창을 쓸지 모르겠으면 방법 A 의 `build.bat` 더블클릭이 가장 간단합니다.)

**B-2. 아래 명령을 한 줄씩, 하나 입력하고 Enter, 끝나면 다음 줄** (복사해서 붙여넣기 해도 됩니다. 검은 창에서는 우클릭이 붙여넣기입니다)

① 가상환경 만들기 (1~2분, 끝나면 `C:\mypass_build>` 가 다시 나타남)

`python -m venv .venv`

② pip(설치 도구) 최신으로

`.venv\Scripts\python.exe -m pip install --upgrade pip`

③ 필요한 패키지 한 번에 설치 (`requirements.txt` 에 적힌 목록대로 설치됨. 1~3분, 마지막에 `Successfully installed ...` 가 나와야 함)

`.venv\Scripts\python.exe -m pip install -r requirements.txt`

④ exe 만들기 (1~3분, 마지막에 `Building EXE ... completed successfully.` 가 나와야 함)

`.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name MyPass --icon icon.ico --collect-all uiautomation --collect-all comtypes mypass.py`

⑤ 끝났으면 `exit` 입력 후 Enter 로 창을 닫습니다. `C:\mypass_build\dist\MyPass.exe` 가 생겼는지 확인합니다.

## 4단계. (참고) 각 명령이 하는 일
| 명령 | 하는 일 |
|---|---|
| `python -m venv .venv` | 이 폴더 안에만 쓰는 독립된 파이썬 공간(가상환경)을 만듭니다. PC 의 다른 파이썬과 섞이지 않습니다. |
| `pip install ... cryptography` | 암호화 기능 |
| `pip install ... uiautomation` | 브라우저 주소 읽기, 채움 기능 (윈도우 전용) |
| `pip install ... pyinstaller` | 파이썬 프로그램을 exe 로 묶는 도구 |
| `PyInstaller ...` | 파이썬과 패키지를 한 파일(MyPass.exe)로 묶습니다. |

## 5단계. 실행해 보기
1. `C:\mypass_build\dist\MyPass.exe` 를 **더블클릭**합니다. (처음엔 몇 초 걸릴 수 있습니다)
2. 로그인 창이 뜨면 성공입니다. `새 사용자` 로 사용자를 만들어 써 보세요.
3. 실행하면 exe 와 **같은 폴더**에 `data` 폴더가 생기고, 정보는 거기에 저장됩니다.
4. 배포하려면 **`MyPass.exe` 파일만** 원하는 곳(USB 등)에 복사하면 됩니다. `build`, `.venv` 폴더 등은 필요 없습니다.
5. 테스트로 만든 사용자 정보는 `dist\data` 폴더를 지우면 없어집니다. (배포할 때 이 폴더는 복사하지 마세요)

---

## 6단계. 나중에 새 버전 만들기
1. `mypass.py` 를 새 것으로 바꿔 넣습니다. (같은 폴더, 덮어쓰기)
2. `build.bat` 를 다시 더블클릭합니다. (`.venv` 가 이미 있어서 훨씬 빠릅니다)
3. 새 `dist\MyPass.exe` 가 만들어집니다.

## 문제 해결

**1. `python` 입력 시 `Python was not found` 가 나오거나 Microsoft Store 가 열림**
- 원인: 파이썬 설치 때 `Add python.exe to PATH` 를 체크하지 않았거나, 윈도우의 스토어 연결 때문입니다.
- 해결 ①: 파이썬 설치 파일을 다시 실행 → `Modify` 또는 `Uninstall` 후 처음부터 다시 설치하며 **PATH 체크**.
- 해결 ②: `Windows 키` → `앱 실행 별칭 관리` 검색 → `python.exe`, `python3.exe` (앱 설치 관리자) 두 항목을 **끔**.
- 설치 후에는 열려 있던 검은 창을 모두 닫고 **새로 열어야** 적용됩니다.
- (참고: `build.bat` 은 `python` 이 없으면 `py` 명령도 자동으로 시도합니다.)

**2. `pip install` 중 `Could not find a version` / `Connection` / `timed out` 오류**
- 인터넷 연결을 확인하고 명령을 다시 실행합니다. 회사·학교 망이면 보안 프로그램이 막을 수 있습니다.

**3. `'.venv\Scripts\python.exe'은(는) 내부 또는 외부 명령...` 오류**
- ① 가상환경 만들기가 실패한 것입니다. `.venv` 폴더를 지우고 `python -m venv .venv` 부터 다시 합니다.
- 명령 프롬프트가 `C:\mypass_build>` 에서 열렸는지 확인하세요.

**4. `can't open file ... mypass.py` / `No such file`**
- `mypass.py` 가 `C:\mypass_build` 바로 안에 없습니다. 2단계 4번을 다시 확인하세요.

**5. `build.bat` 을 열었는데 글자가 깨져 보임**
- 창은 동작에 영향 없습니다. 방법 B 로 진행해도 됩니다.

**6. 백신이 exe 를 삭제하거나 "위협" 이라고 표시**
- 직접 만든 서명 없는 exe 에서 자주 나오는 오탐입니다. `dist` 폴더와 `MyPass.exe` 를 백신 예외 목록에 추가한 뒤 다시 만드세요.

**7. exe 실행 후 아무 창도 안 뜸**
- 10~20초 기다려 봅니다. 그래도 없으면 백신(6번) 확인, 작업 관리자에 `MyPass.exe` 가 남아 있으면 종료 후 다시 실행합니다.
- 계속 안 되면 `python mypass.py` 로 직접 실행해 오류 메시지를 확인할 수 있습니다:
  `.venv\Scripts\python.exe mypass.py` (이때는 `pyinstaller` 없이도 실행됩니다)

**8. `ModuleNotFoundError: No module named ...`**
- 3단계 ③(패키지 설치)이 끝까지 되지 않은 것입니다. ③을 다시 실행하세요.
