# 마이패스 설치·사용 가이드

## 0. 먼저 알아둘 것
- **사용하는 사람**: `MyPass.exe` 하나만 있으면 됩니다. 파이썬·설치 프로그램 필요 없음.
- **exe를 만드는 사람**(한 PC에서 한 번): 파이썬이 필요합니다. → 4번 참고
- **마스터 비밀번호를 잊으면 복구할 방법이 없습니다.** 반드시 기억해 두세요.

## 1. 설치 (exe 받은 경우)
1. `MyPass.exe` 를 원하는 폴더에 둡니다. 예: `D:\MyPass\`
   - `C:\Program Files` 처럼 쓰기 권한이 없는 곳은 피하세요. (쓸 수 없으면 정보가 `%APPDATA%\마이패스\data` 에 저장됩니다)
2. 더블클릭으로 실행합니다. 실행하면 exe 옆에 `data` 폴더가 생깁니다. **모든 정보는 이 폴더에만 저장됩니다.**
3. 처음 실행 시 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. (서명 없는 개인 프로그램이라 나오는 경고)
   → `추가 정보` → `실행` 을 누르세요. 백신이 의심하면 해당 exe 를 예외로 등록하세요.

## 2. 처음 사용하기
1. 로그인 창에서 `새 사용자` → 아이디와 **마스터 비밀번호** 정하기
2. `관리 → 사이트 추가` (Ctrl+N): 사이트 설명, 주소, 아이디, 비밀번호 입력
   - 그룹은 만들어서 묶을 수 있고, 목록에서 끌어다 놓아 옮길 수 있습니다.
3. 브라우저에서 해당 사이트를 열면 주소가 자동으로 연동되어 맞는 정보가 나타납니다. (`브라우저 주소 자동 연동`, F5 로 수동 가져오기)
4. `채움` 버튼: 로그인 창에 아이디/비밀번호를 입력해 줍니다. (`채움 후 Enter` 옵션으로 자동 로그인)
   - 브라우저 연동·채움은 윈도우의 접근성 기능(UI Automation)을 쓰므로, 사이트·브라우저에 따라 동작이 다를 수 있습니다. 안 되면 아이디/비밀번호 복사 버튼을 쓰세요.
5. 10분간 조작이 없으면 자동으로 잠깁니다.

## 3. 백업 (꼭 설정하세요)
- **자동 백업**: 로그인할 때마다 `data\backup` 에 암호화 백업이 쌓입니다. (최근 10개 보관)
- **백업 위치**: `파일 → 백업 위치 설정...` 에서 폴더를 지정하면 그 폴더(`MyPass_backup`)에 암호화 백업이 자동 저장됩니다.
  - 다른 드라이브, 외장하드, NAS, OneDrive·구글 드라이브·Dropbox 같은 클라우드 동기화 폴더 모두 가능
  - 프로그램 폴더(USB)와 **다른 장치**를 권장합니다. 그 장치가 고장 나면 원본과 백업이 같이 사라집니다.
  - CSV 형식은 암호화되지 않으니 가급적 쓰지 마세요.
- **복원**: 로그인 창 또는 `파일 → 백업에서 복원...`

## 4. exe 만들기 (만드는 사람만, 처음 한 번)
**`빌드가이드.md` 를 열어 1단계부터 순서대로 따라 하세요.** (파이썬 설치 → 폴더 준비 → 만들기 → 실행 확인까지 전부 적혀 있습니다)
- 요약: 파이썬 설치 → `mypass_package.zip` 안의 파일들(`mypass.py`, `build.bat`, `requirements.txt`, `fonts` 폴더, `icon.ico` 등)을 한 폴더에 → `build.bat` 더블클릭 → `dist\MyPass.exe`

## 5. USB에 넣어 들고 다니기
- `MyPass.exe` 와 `data` 폴더를 USB의 한 폴더에 함께 두고, USB에서 바로 실행하면 됩니다.
- 여러 PC에서 써도 정보는 USB의 `data` 에만 있습니다.
- USB가 쓰기 금지(읽기 전용)이면 정보가 그 PC의 `%APPDATA%` 에 따로 저장됩니다. 주의하세요.
- 분실에 대비해 마스터 비밀번호를 충분히 길게 하고, 백업 위치를 따로 지정하세요.

## 저작권 표시
`mypass.py` 맨 위 `COPYRIGHT_HOLDER` 에 넣은 이름이 정보(About) 창에 `ⓒ 올해연도 이름` 형식으로 표시됩니다. 바꾸려면 그 한 줄만 고치세요.

## 7. 문제 해결
| 증상 | 해결 |
|---|---|
| 실행이 안 됨 / 바로 사라짐 | 백신 예외 등록, 다른 폴더(예: 바탕화면 아닌 D:\)에서 실행 |
| 정보가 사라진 것 같음 | 이전에 다른 폴더에서 실행했다면 그 폴더의 `data` 또는 `%APPDATA%\마이패스\data` 를 확인 (`도움말 → 정보 → 데이터 폴더 열기`) |
| 브라우저 주소가 안 읽힘 | `F5`, 브라우저를 한 번 클릭 후 재시도. 안 되면 주소를 직접 입력 |
| 비밀번호 분실 | 복구 불가. 비밀번호를 기억하는 백업이 있으면 `백업에서 복원` |

## 8. 알아둘 점
- 프로그램은 인터넷으로 정보를 보내지 않습니다.
- 암호화: AES-256-GCM, 키 생성: scrypt
- 개인 정보가 들어 있는 `data` 폴더, `.mpbak`, `.csv` 파일은 GitHub 등에 올리지 마세요. (함께 드린 `.gitignore` 가 막아 줍니다)
