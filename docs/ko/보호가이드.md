# 코드 보호(Nuitka) 가이드 — 선택 사항

`build.bat`(PyInstaller)로 만든 exe는 파이썬 코드가 "바이트코드" 상태로 들어 있어서, 메모장으로는 안 보이지만 `uncompyle6` 같은 전용 도구로 **디컴파일을 시도하면 원래 소스에 가깝게 복원**됩니다.

이 가이드는 **Nuitka**라는 도구로 파이썬 코드를 아예 **C 언어로 바꿔서 기계어(machine code)로 컴파일**하는 방법입니다. 바이트코드가 아니라 진짜 실행 파일이 되기 때문에, 일반적인 파이썬 디컴파일 도구가 통하지 않습니다. 현재 나와 있는 보호 방법 중 **무료로 쓸 수 있는 것 중에서는 가장 강력한 축**에 속합니다.

> 먼저 정정: 이전 답변에서 PyArmor를 "가장 강력한" 방법으로 안내드렸는데, PyArmor는 CLI 도구 자체는 pip로 받을 수 있지만 **문자열 암호화 등 실질적인 보호 기능과 상업적 사용은 유료 라이선스가 있어야** 합니다(공식 문서에 "Free To Use But Restricted"라고 스스로 적어 두었고, 체험판은 상업 제품에 못 쓴다고 명시돼 있습니다 — [출처](https://pyarmor.readthedocs.io/en/v8.2/licenses.html)). 확인 과정 자체는 제대로 했지만, 결제가 필요하다는 걸 먼저 분명히 말씀드렸어야 했습니다. 그래서 기본값을 **완전 무료·오픈소스인 Nuitka**로 바꿉니다. (Nuitka는 Apache 계열이 아니라 AGPLv3 라이선스이지만, "컴파일해서 나온 실행 파일(exe)에는 적용되지 않는다"는 예외 조항이 있어서, 여러분이 만든 MyPass.exe를 소스코드 없이 그대로 배포해도 됩니다 — [출처](https://nuitka.net/pages/overview.html))

## 1. 보호 빌드 실행

`빌드가이드.md`의 2단계까지 똑같이 따라 해서 `mypass_package.zip` 안의 파일들(`mypass.py`, `build.bat`, `build_protected.bat`, `requirements.txt`, `requirements-protected.txt`, `fonts` 폴더, `icon.ico` 등)을 한 폴더(`C:\mypass_build` 등)에 모아 둔 다음, 이번에는 `build.bat` 대신 **`build_protected.bat`** 를 더블클릭하세요.

- 패키지 설치, 컴파일, exe 만들기까지 자동으로 진행됩니다.
- **처음 한 번은 C 컴파일러를 자동으로 내려받기 때문에 훨씬 오래 걸립니다(10분 이상 가능).** "WARNING"이 보여도 중간에 끄지 말고 기다리세요.
- 완료되면 `dist\MyPass.exe` 가 만들어집니다. (일반 빌드와 파일 이름·위치는 같습니다)

## 2. 알아 둘 점 (꼭 읽어 주세요)

- **채움·브라우저 연동 부분(uiautomation/comtypes)은 제가 직접 테스트하지 못했습니다.** comtypes는 실행 중에 필요한 코드를 그때그때 만들어 쓰는 방식이라, Nuitka로 컴파일한 exe 안에서도 똑같이 잘 동작하는지는 실제 Windows에서 한 번 확인이 필요합니다. 안 되면 `build.bat`(PyInstaller) 쪽은 이미 확인된 방식이니 그걸 쓰시면 됩니다.
- **실행 파일 용량과 첫 실행 속도**가 PyInstaller보다 좀 더 크거나 느릴 수 있습니다(컴파일된 런타임을 포함하기 때문). 기능상 문제는 아닙니다.
- 서명되지 않은 exe라 Windows 보안 경고(파란 화면, "알 수 없는 게시자")가 뜰 수 있습니다. 이건 PyInstaller로 빌드해도 똑같이 뜨는 문제라, Nuitka 때문만은 아닙니다. 배포를 늘리려면 코드 서명 인증서를 고려하세요.
- 업데이트(6단계, `빌드가이드.md`)도 `mypass.py`를 바꾼 뒤 이번에는 `build_protected.bat`를 다시 실행하면 됩니다.

## 3. (참고) PyArmor — 유료 대안

문자열까지 암호화하는 PyArmor 같은 방식을 추가로 쓰고 싶다면 선택지로 남겨 둡니다. 다만:

- **무료 체험판은 상업적 배포에 쓸 수 없습니다.** 실제로 쓰려면 Pro 또는 Group 라이선스(1회성 결제, 가격은 PyArmor 쪽 정책에 따라 바뀔 수 있음)가 필요합니다 — 구매 전 [공식 라이선스 페이지](https://pyarmor.readthedocs.io/en/latest/licenses.html)에서 최신 조건을 꼭 확인하세요.
- Nuitka처럼 기계어로 바꾸는 게 아니라 "암호화된 바이트코드 + 복호화 코드"라서, Nuitka와 같이 쓰는 건 의미가 없습니다. 둘 중 하나만 고르면 됩니다.
- 라이선스 종류에 따라 사용자 PC가 인터넷에 연결돼 있어야 처음 실행되는 경우가 있어서, USB로 들고 다니는 용도와는 궁합이 덜 좋습니다.

필요하시면 PyArmor용 빌드 스크립트도 따로 만들어 드릴 수 있지만, 비용 문제가 없다면 **Nuitka(무료) 쪽을 기본으로 권합니다.**
