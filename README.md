# 마이패스 (MyPass)

[한국어](README.md) · [English](docs/en/README.md) · [日本語](docs/ja/README.md) · [简体中文](docs/zh-CN/README.md)

Windows용 개인정보(아이디·비밀번호·사이트) 암호화 저장 프로그램입니다. 인터넷으로 정보를 보내지 않고, 이 컴퓨터(또는 USB)의 `data` 폴더 안에만 암호화해서 저장합니다.

## 주요 기능

- **암호화**: AES-256-GCM + scrypt. 마스터 비밀번호 없이는 열 수 없습니다.
- **다중 사용자**: 한 컴퓨터에서 여러 사람(또는 용도별)이 각자의 보관함을 따로 씁니다.
- **그룹(폴더) 관리**: 사이트를 그룹으로 묶고, 끌어서 옮길 수 있습니다.
- **검색**: `Ctrl+F` 로 사이트 설명·주소·키워드·아이디를 한 번에 찾을 수 있습니다.
- **브라우저 주소 연동 · 채움**: 크롬·엣지·웨일 등에서 주소를 자동으로 읽고, 아이디·비밀번호를 자동 입력합니다. (Windows 전용, UI Automation 사용)
- **백업**: 로그인마다 자동 백업, 원하는 위치(USB·클라우드 폴더 등)로 자동/수동 백업. 기본은 암호화 백업이며, 필요하면 암호화되지 않은 CSV로도 내보낼 수 있습니다(경고 표시).
- **USB로 들고 다니기**: exe 옆에 `data` 폴더를 두는 구조라, USB에 통째로 넣고 다른 컴퓨터에서 바로 써도 됩니다.
- **자동 업데이트 알림/적용**: 새 버전이 나오면 알려주고, exe로 실행 중이면 [지금 업데이트] 한 번으로 받아서 바꿔 넣고 다시 시작합니다. 정보는 보내지 않고, 새 버전 확인에만 인터넷을 씁니다.
- **다국어**: 한국어 · English · 日本語 · 简体中文. 처음 실행할 때 고르거나, `환경설정 → 언어`에서 언제든 바꿀 수 있습니다.

## 받아서 쓰기

GitHub 저장소의 **Releases**에서 최신 `MyPass.exe`를 받아 실행하면 됩니다. 파이썬 설치가 필요 없습니다. exe 옆에 `data` 폴더가 자동으로 생기고, 정보는 모두 그 안에 암호화되어 저장됩니다. (USB에 exe와 data 폴더를 같이 넣어 들고 다닐 수 있습니다)

## 새 버전 배포(관리자용)

GitHub 저장소 Releases 에서 태그(예: `v2.2`, 현재 버전보다 큰 숫자)를 만들고 **exe를 반드시 첨부파일(Assets)로 함께 올리세요.** `mypass.py` 의 `UPDATE_REPO`(기본 `vhost-lab/mypass`)에 미리 지정된 저장소의 최신 Release 를 확인해 사용자에게 새 버전을 알리고, exe 가 첨부돼 있으면 [지금 업데이트]로 자동 교체·재시작까지 합니다. (메뉴: 업데이트)

## 안전성

- 모든 정보는 AES-256-GCM으로 암호화되어 이 컴퓨터에만 저장됩니다. 인터넷으로 전송되지 않습니다.
- 인터넷은 업데이트 확인(그리고 업데이트 적용 시 새 exe 다운로드)에만 쓰이며, 저장된 정보는 전혀 전송되지 않습니다.
