🛡️ MyPass (패스워드 관리자)
안전하고 직관적인 로컬 기반 패스워드 관리 프로그램입니다.

📌 주요 기능
 * 안전한 로컬 암호화 저장: 중요한 계정 정보와 비밀번호를 외부 서버에 의존하지 않고 안전하게 로컬 환경에 암호화하여 보관합니다.
 * 직관적인 사용자 인터페이스: 복잡한 설정 없이 누구나 쉽고 빠르게 계정 정보를 추가, 수정, 조회할 수 있습니다.
 * 다국어 지원: 한국어를 기본으로 다양한 언어 환경을 고려하여 설계되었습니다.
