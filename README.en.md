# 🛡️ MyPass (Password Manager)

A secure and intuitive local-based password management application.

## 📌 Key Features
* **Secure Local Encryption:** Keeps your sensitive account credentials and passwords securely encrypted on your local machine without relying on external servers.
* **Intuitive User Interface:** Easily add, edit, and view account information without complicated configurations.
* **Multi-language Support:** Designed with a flexible multi-language environment including English, Korean, Japanese, and Chinese.
